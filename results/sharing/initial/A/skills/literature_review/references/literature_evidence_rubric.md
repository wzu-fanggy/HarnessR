# 文献综述证据质量检查表

## 必须满足
- [ ] 每条论断都标注 `[chunk_id]` 来源
- [ ] 不引用模型参数知识里的文献
- [ ] 工具返回为空时明确说明"未检索到相关文献"
- [ ] 区分已有共识、存在争议、文献数据有限三类陈述

## 禁止行为
- [ ] 把多篇文献性能数值迁移到未经验证的组合
- [ ] 输出"【推断】"开头的句子
- [ ] 把综述中转述的原始文献结论伪装成一手文献

## 检索充分性
- [ ] 至少使用 2–4 个不同角度查询
- [ ] 优先使用 `search_literature_multiview`
- [ ] 结果不足时换关键词再次检索
